# 模板范围

## 已包含的基础能力

- Vue 3 / Vite / Nuxt UI 中文管理后台。
- NestJS / Prisma / PostgreSQL API，后台与小程序分别使用 `/api/admin`、`/api/miniapp` 入口。
- 内部员工认证、访问令牌与刷新会话、个人资料、用户、角色、菜单和资源操作权限。
- 部门、岗位、通讯录、字典、审计日志、公告、通知和基础系统统计。
- uni-app / Vue 3 / Pinia / UnoCSS 微信小程序工程，包含请求、状态持久化、公开环境配置及示例页面。
- `packages/shared` 中的纯 TypeScript 响应契约、常量和权限定义。
- 配置补缺脚本、数据库迁移与种子数据、独立测试库保护、构建和检查命令。

## 需要新项目实现的部分

- 小程序客户登录、客户身份模型及对应的数据权限。
- 业务页面、导航、业务接口、数据库模型和迁移。
- 按实际需求接入文件存储、消息、支付或其它外部服务。
- 正式部署域名、微信 AppID、品牌资源和运行配置。

示例页面、历史用户接口类型和演示图表只作开发参考，不表示对应业务已实现。后台员工身份不能直接用于小程序客户登录。

## 新项目验收原则

先在本文件明确需求和范围，再实现业务。新增功能同时维护接口契约、资源权限、前端类型、数据库迁移和关键测试；授权、认证、事务及状态转换需要有意义的回归验证。

首次使用与重命名步骤见 [模板使用指南](template.md)。
